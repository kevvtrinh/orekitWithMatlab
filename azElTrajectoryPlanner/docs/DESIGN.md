# Design: Deterministic Quintic Space-Time Lattice

## Problem model

The planner operates only on the neutral `scenario` contract. Its continuous
state is `(azimuth, elevation, velocity, acceleration, time)` and its control
is jerk. Azimuth is continuous internally and wrapped only at the public
boundary. Every motion edge is a two-axis quintic polynomial with specified
position, velocity, and acceleration at both ends. A hold edge is the same law
with identical stationary endpoints.

The cost is angular path length with a small elapsed-time tie breaker. A fixed
goal is satisfied at its requested final state and time. An intercept is a
terminal connector to one target state within the declared candidate window.
Tracking appends target-law segments only after a dynamically matched
intercept. Ordinary failure is classified as infeasible only when an analytic
obstacle-free deadline certificate fails; otherwise exhausted search is
reported as inconclusive.

Obstacle geometry follows the manifest exactly: nearest source slice, no
extrapolation, one adjacent slice of temporal padding, Euclidean edge margin,
and equivalent azimuth images at plus or minus 360 degrees. Search and final
validation call the same collision invariant.

## Considered families

| Family | Kinematics | Moving obstacles | Runtime/memory | Complexity |
|---|---|---|---|---|
| Kinodynamic sampling tree | Natural state/control propagation, but terminal derivatives are difficult to hit exactly | Natural | Probabilistic runtime; large tuning surface | High, especially deterministic replay and terminal matching |
| Direct nonlinear trajectory optimization | Smooth derivatives and compact variables | Natural | Sensitive to initialization and obstacle topology; no reliable deep-detour discovery | Moderate solver code but complex feasibility behavior |
| Deterministic space-time lattice with quintic edges | Exact endpoint derivatives and analytic component extrema | Time is an explicit state coordinate | Bounded and deterministic; resolution-dependent memory | Small coherent search plus one trajectory law |

The deterministic lattice is selected because it exposes every feasibility
decision, discovers arbitrary topology without route hints, supports waiting
as a legal stationary edge, and uses the same edge law for propagation,
reconstruction, collision sampling, and validation.

## Representation and search

Grid spacing and time step are selected uniformly from domain extent and time
horizon; the rules never read fixture identity, names, descriptions, seeds,
acceptance fields, or known coordinates. Primitive density is scaled only by
general workload properties. Static scenes use the full multiscale stencil.
Short scenes with at most three obstacle timelines use seven radii and 16
directions; four-timeline scenes use four radii and 16 directions; larger or
long low-count scenes use four radii and eight directions. Each node is
stationary except the initial node. The first edge handles nonzero initial
derivatives; terminal connectors handle nonzero goal or target derivatives.

Static geometry, including the invariant subset of a mixed scene, receives a
reverse eight-neighbor distance field built with the same polygon occupancy
rule. It changes search ordering only. Static straight segments use exact
polygon/segment and Euclidean-margin checks. Dynamic segments first check the
static subset exactly, then use a coarse rejection pass followed by the
authoritative fine subdivision for moving obstacles.

For dynamic geometry, state identity is `(grid cell, discrete time index)`.
For invariant geometry, earlier arrival dominates later arrival at the same
cell because a verified stationary hold can reproduce any later departure.
The open set is a binary heap. A label is reopened only when its cost improves.
Transitions are rejected in this order: bounds, terminal deadline, analytic
velocity/acceleration/jerk extrema, endpoint occupancy, then subdivided edge
collision. A stationary one-step hold is generated by the same transition
path. Fixed resting goals also use an analytic obstacle-free rest-to-rest
lower bound to prune states that cannot meet the remaining deadline.

Dynamic queue scaling uses only obstacle timeline count. Low-count scenes use
motion/wait weights 0.5 and 0.01 with base heuristic weight 1; four-timeline
scenes use dense motion/wait weights 0.1 and 6 with base heuristic weight 3;
larger scenes use the same dense costs with base heuristic weight 8. Terminal
urgency grows gradually over the horizon, except in long low-static-complexity
scenes where it is delayed until the final fifth so patrol motion can develop.

Goal candidates are not a separate planner. Fixed goals provide one terminal
state. Moving requests provide target states interpolated at declared times.
Popped lattice labels attempt the same quintic terminal connector against
those states. Tracking uses quintic target-law segments after capture until
the requested end or the first collision boundary.

## Termination and reconstruction

Search terminates on the first feasible weighted-distance connector, or on
wall-time/state budgets. The topology distance guides deterministic search; it
is not an optimality certificate. Parent labels and the
accepted quintic endpoints reconstruct one segment sequence. Output sampling,
collision checking, diagnostics, and final validation all evaluate that
sequence through one segment evaluator.

A bounded rolling refinement is available for time-varying fixed-goal
connectors. The two-stage form is local and available for every obstacle
count; the larger three-stage search is limited to at most three timelines.
Both search uniform split, position, and velocity fractions, preserve C2
continuity, and use the same extrema and collision invariants. They refine a
terminal edge rather than forming another planner.

Two bounded reconstruction refinements preserve the same segment law. Small
static layouts may replace a lattice route with a shorter validated visibility
route. In a dynamic fixed-goal plan with more than 20 seconds of terminal
dwell, one second may be relocated to the earliest stationary join whose
entire shifted suffix remains valid. The latter preserves path and final time
while exposing a safe intermediate hold.

## Guarantees

- Quintic endpoint position, velocity, and acceleration are exact to floating
  point precision.
- Velocity, acceleration, and jerk extrema are checked analytically from
  polynomial derivative roots.
- Joins are `C2`; jerk may change finitely at a join but never impulses.
- Static straight-edge collision is exact for the polygon-plus-margin model.
  Other edges are resolution-dependent and subdivided no more coarsely than
  both the collision and public sample steps; the unchecked interval is reported.
- Search is deterministic and complete only for the finite lattice,
  primitive set, time discretization, and resource budget.
- The fixed-resting-goal deadline prune is an obstacle-free mathematical lower
  bound and cannot remove a feasible lattice completion.
- No probabilistic or global continuous-space completeness claim is made.
