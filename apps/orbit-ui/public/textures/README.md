## earth_daymap_8k.png

NASA **The Blue Marble: Land Surface, Ocean Color and Sea Ice** (2002).
This is the original, unmodified 8192 × 4096 PNG downloaded from NASA on
September 7, 2026 (24,147,269 bytes). The global equirectangular map contains
land surface, ocean color, and sea ice, with natural-color satellite imagery.
